# Instalación — Página Web Aurea Salud

Prototipo estático **HTML/CSS/JS**. No requiere compilación ni backend para la vista principal.

## Opción A — abrir directo

Doble clic en `Paginas/index.html` (o usar `abrir_pagina.bat` en Windows,
ajustando antes la ruta interna a tu equipo).

## Opción B — servidor local

```bash
python3 -m http.server 8080
# → http://localhost:8080/Paginas/
```

## Notas

- `php/` contiene experimentos de backend que no forman parte del flujo principal.
- Proyecto de formación, deliberadamente inconcluso.
